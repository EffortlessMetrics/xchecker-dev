## 2026-04-14 - TUI Help Footer Alignment and Discoverability
**Learning:** Ratatui `Paragraph` blocks inherit alignment rules from their contents unless explicitly overridden. When center-aligning a help footer using `.alignment(Alignment::Center)` on the `Paragraph`, it accidentally center-aligns the `Block` title as well. In addition, existing keyboard shortcuts (`Home/End`, `Esc` on main view) were fully implemented in the event loop but completely hidden from the user because they weren't documented in the help text.
**Action:** When applying `Alignment::Center` to Ratatui paragraphs containing blocks, explicitly format the block title with `Line::from(" Title ").alignment(Alignment::Left)` to maintain clear visual boundaries. Always grep for actual event handlers (`KeyCode`) when documenting UI shortcuts to ensure all implemented shortcuts are discoverable.
