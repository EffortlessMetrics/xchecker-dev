## 2024-05-15 - Visual Hierarchy in TUI Empty States
**Learning:** Secondary TUI empty states (e.g., 'No spec selected' in details panel) need visual distinction from primary empty states (e.g., missing specs list) to prevent user confusion.
**Action:** Use center alignment and muted colors (like `Color::DarkGray`) for secondary empty states and footers to establish a clear visual hierarchy distinct from actionable core content.
