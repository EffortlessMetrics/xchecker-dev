## 2024-04-14 - Fix TOCTOU Vulnerability in File Reading
**Vulnerability:** Use of `std::fs::read_to_string` causes TOCTOU and potential DoS by uncontrolled memory consumption (unbounded file reads).
**Learning:** `std::fs::read_to_string` does not guard against file size changes or arbitrarily large files. Memory mentions: "To prevent TOCTOU vulnerabilities when reading files, open the file first with `fs::File::open` and check `file.metadata()`. To prevent memory exhaustion (DoS), avoid using `metadata.len()` directly as a limit for `take()`, as this can silently truncate growing files or return empty strings for zero-sized pseudo-files (like those in /proc). Instead, return an explicit error if `metadata.len()` exceeds a reasonable static maximum (e.g., 10MB), and use `std::io::Read::take(&mut file, static_bound).read_to_string(...)` as a bounded safety net."
**Prevention:** Always use a safe bounded read function, such as `secure_read_to_string`, for untrusted or system files.
